## Defined (derived) objects

| Term | Definition | Source |
|---|---|---|
| Object | a structure of Φ that retains identifiability under propagation: an invariant set (Φ_t(O) = O), an attractor (dist(Φ_t(δ), O) → 0), or a metastable set (τ_internal ≪ τ_lifetime) | D1, rigorized fourth intake |
| Observation | the coupling that maps a difference into a propagation | D2 |
| Learning | update of the propagation law (U acting on Φ) | A4 — currently outside 𝓜 (OP-9) |
| Cognition | an instance, not a foundation | `mappings/cognition.md` |

Instances under D1 (DISCUSSION): a vortex is a coherent structure of the
flow, not the water; an organism a far-from-equilibrium metastable
organization, not its cells; a long-term personality a metastable region of
cognitive dynamics; an institution a stable attracting basin of social
dynamics. An object is not the material — it is *the structure that stays
identifiable while propagating*.
