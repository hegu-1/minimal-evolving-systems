| OP-16 | **Novelty gate.** As written, the static class + P-1 reconstruct classical dissipative dynamical systems theory (see `references/bibliography.md`). Locate the delta: candidate loci are (i) K as a first-class object, (ii) the U-layer / two-layer coupling (v2's core; compare against adaptive-dynamics, meta-learning, and non-autonomous systems literature before claiming it), (iii) the cross-domain representation discipline (C-001 v2); **(iv) the question class itself** — see the reframe below. No external novelty claim before this is answered. **Reframe (2026-08-02, Writer; maintainer-directed to record it).** Loci (i)–(iii) all ask the delta as *"which theorem here beats a classical one?"* That framing may be the wrong one for this project, because it is a framing borrowed from the literature being compared against. The comparison targets in `references/bibliography.md` are almost uniformly **modeling** work: a specific system is given (a PDE, an ecology, an optimizer, a game) and its properties are derived. This project asks the opposite question — *which mathematical objects are minimally necessary for a system to persist and evolve* — which is a **foundational** question class. The two classes have different natural products: modeling produces existence and characterization results; a foundational question produces **impossibility and minimality** results ("without this object the phenomenon cannot occur"). Such results are structurally rare in modeling literature, not because they are known, but because no one has occasion to prove them. P-10 is the first instance in this repository: it does not claim a system that branches, it proves a class that cannot. **Guard — this reframe is dangerous and is not a licence.** It can degrade into an excuse ("we are not new because we are foundational"), which would hollow out OP-16 entirely. It counts only when it produces a *specific statement* that the modeling literature would neither ask nor answer, and that statement must still survive the ordinary search. The first candidate is C-003 (v2) c₁ (a fixed outer objective forbids diversification); its search is incomplete — see the attack log — so nothing is settled. If the reframe cannot produce a second such statement, it is an excuse and should be deleted. | OPEN — blocks any public claim |
