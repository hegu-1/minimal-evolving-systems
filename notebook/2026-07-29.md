- **P-5 (all finite n) — non-gradient is necessary.** LaSalle: on a compact

## Self-audit of P-5/P-6 before hand-off (Writer, same day)

At the maintainer's request ("审"), the Writer ran an adversarial pass on its own
P-5/P-6 draft — the repo's attack-loop executed inside one agent before commit.
Four real defects found and fixed; both cores (LaSalle for P-5, Poincaré–
Bendixson for P-6) held. Recorded here for the Formalizer to cross-check against.

1. **P-5 — definitional bug (load-bearing).** The gate had been defined as "an
   attracting set S with S ⊄ E (S contains a non-equilibrium point)." A gradient
   flow's global attractor already satisfies this — it is the equilibria *plus
   their heteroclinic connections*, which contain non-equilibrium points — so the
   definition would falsely call gradient systems "gate-open." Fix: state the gate
   via ω-limit sets / recurrence — *open* iff some ω(δ₀) ⊄ E. LaSalle's
   conclusion (ω(δ₀) ⊆ E under (G)) is exactly what closes the gate under the
   corrected definition. Core unaffected; packaging corrected.

2. **P-6 — sign error in the Lyapunov equation.** Written as
   (−B_i)ᵀP + P(−B_i) = I, which yields B_iᵀP + P B_i = −I and V̇ = −‖x‖² < 0 —
   a *sink*, contradicting "source." Correct Hurwitz form (RHS −I):
   (−B_i)ᵀP + P(−B_i) = −I ⇒ B_iᵀP + P B_i = I ⇒ V̇ = ‖x‖² > 0. Intent right,
   symbol wrong.

3. **P-6 — collar geometry imprecision.** The repelling collar D_i was a
   Euclidean ball ‖δ−p_i‖ ≤ r_i, but the outward-flux estimate is in the
   P_i-weighted norm V_i, whose level sets are ellipses; normals disagree. Fix:
   take D_i = {V_i ≤ ρ_i} (a V_i-sublevel ellipse), so ∇V_i is the outward normal
   on ∂D_i and V̇_i > 0 gives genuine outward flux.

4. **P-6 — factual error in R2.** The remark claimed Lorenz is an instance of
   "all-source equilibria in a trapping region ⇒ chaos in n ≥ 3." Lorenz's
   equilibria are *saddles* (and saddle-foci), not sources, so it does **not**
   satisfy hypothesis (R). Fix: Lorenz now cited only to show the n ≥ 3 gate can
   open onto chaos (defeating any planar-cycle conclusion), with an explicit
   caveat that it is not an (R)-instance. The (R)-question in n ≥ 3 remains open.

Method note: defects 1 and 4 are the instructive ones — both are cases where a
statement is *almost* right and reads convincingly, and only an explicit
counterexample search (gradient-attractor for #1, checking Lorenz's actual
spectrum for #4) exposes the gap. Consistent with the protocol's Counterexample
Test being a first-class gate, not an afterthought.
