## OP-14: P-7 — the gate opens in every dimension; the "n≥3 hard core" was overstated (Writer)

Maintainer directive: keep pushing OP-14 forward (attack the n ≥ 3 core flagged
2026-07-29). Working the core produced a **correction of my own prior framing**,
not a hard Conley-index theorem.

**P-7 (all finite n).** Under (R) — every equilibrium in a P-1 absorbing region
is a source — every non-equilibrium trajectory has a non-trivial ω-limit set
(ω(x) ⊄ E), so the gate is open in every dimension. Proof is short:
- a source has empty stable set (the P-6 Lyapunov collar, globalized: a
  trajectory converging to p would eventually be trapped in the collar where V
  strictly increases, contradicting V → 0);
- ω(x) is nonempty, compact, invariant, **connected** (classical);
- if ω(x) were a single point it would be a source, forcing x into that source's
  (trivial) stable set — impossible for x ∉ E;
- connected + ≥ 2 points ⇒ infinite ⇒ ⊄ the finite set E.

**What this corrects.** On 2026-07-29 I wrote (P-6 R2 + notebook) that n ≥ 3 was
"the remaining hard core," implying a topological/Conley-index argument was
needed to open the gate. **That conflated two questions.** Opening the gate
(is ω(x) ⊄ E?) is *not* dimension-hard — P-7 does it in three classical lines,
all n. What is hard is (i) the **source/unstable gap** — for saddles the collar
argument fails and the gate can close (gradient flow with saddles), so (R) is
not weakenable to "unstable" for free; and (ii) **classifying** the forced
non-trivial set (cycle / torus / strange attractor), which is where Lorenz and
genuine 3D difficulty live, and which is arguably outside OP-14's minimal-
conditions remit.

**Net picture of OP-14 now.** P-5 (necessary: non-gradient) and P-7 (sufficient:
all-source, all n) bracket the gate; P-6 refines the planar case to a periodic
orbit. The gate itself is settled under the all-source hypothesis. The residue
is narrowed and honest: the saddle geometry (i) and the classification (ii).
Updated: `book/08_open_problems.md` (OP-14 residue restated), `book/05_propositions.md`
(P-7 added; P-6 entry softened from "isolates n≥3" to "planar strong form"),
`proofs/p006` R2 (framing-correction pointer to P-7).

**Method note.** This is the third self-correction in this OP-14 arc: 07-29
caught four proof-level defects in P-5/P-6 pre-commit; 08-01 catches a
*conceptual* over-statement (mis-locating the difficulty). Recording it because
the mis-location is the more instructive error — a plausible-sounding "this is
the hard part" can be as wrong as a sign error, and only doing the proof exposes
