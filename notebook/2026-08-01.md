## OP-14: P-7 — the gate opens in every dimension; the "n≥3 hard core" was overstated (Writer)

Maintainer directive: keep pushing OP-14 forward (attack the n ≥ 3 core flagged
2026-07-29). Working the core produced a **correction of my own prior framing**,
not a hard Conley-index theorem.

**P-7 (all finite n).** Under (R) — every equilibrium in a P-1 absorbing region
is a source — every non-equilibrium trajectory has a non-trivial ω-limit set
(ω(x) ⊄ E), so the gate is open in every dimension. Proof is short:
- a source has empty stable set (the P-6 Lyapunov collar, globalized: a
  trajectory converging to p would eventually be trapped in the collar where V
  strictly increases, contradicting V → 0);
- ω(x) is nonempty, compact, invariant, **connected** (classical);
- if ω(x) were a single point it would be a source, forcing x into that source's
  (trivial) stable set — impossible for x ∉ E;
- connected + ≥ 2 points ⇒ infinite ⇒ ⊄ the finite set E.

**What this corrects.** On 2026-07-29 I wrote (P-6 R2 + notebook) that n ≥ 3 was
"the remaining hard core," implying a topological/Conley-index argument was
needed to open the gate. **That conflated two questions.** Opening the gate
(is ω(x) ⊄ E?) is *not* dimension-hard — P-7 does it in three classical lines,
all n. What is hard is (i) the **source/unstable gap** — for saddles the collar
argument fails and the gate can close (gradient flow with saddles), so (R) is
not weakenable to "unstable" for free; and (ii) **classifying** the forced
non-trivial set (cycle / torus / strange attractor), which is where Lorenz and
genuine 3D difficulty live, and which is arguably outside OP-14's minimal-
conditions remit.

**Net picture of OP-14 now.** P-5 (necessary: non-gradient) and P-7 (sufficient:
all-source, all n) bracket the gate; P-6 refines the planar case to a periodic
orbit. The gate itself is settled under the all-source hypothesis. The residue
is narrowed and honest: the saddle geometry (i) and the classification (ii).
Updated: `book/08_open_problems.md` (OP-14 residue restated), `book/05_propositions.md`
(P-7 added; P-6 entry softened from "isolates n≥3" to "planar strong form"),
`proofs/p006` R2 (framing-correction pointer to P-7).

**Method note.** This is the third self-correction in this OP-14 arc: 07-29
caught four proof-level defects in P-5/P-6 pre-commit; 08-01 catches a
*conceptual* over-statement (mis-locating the difficulty). Recording it because
the mis-location is the more instructive error — a plausible-sounding "this is
the hard part" can be as wrong as a sign error, and only doing the proof exposes
it. The Minimality/Counterexample discipline applies to difficulty claims too.

**Status.** P-7 written by the Writer, complete proof, self-audited.

## OP-14: P-8 — the saddle gap (i) closes; OP-14's own hypothesis was right (Writer)

Maintainer directive: attack residue (i). It resolved cleanly — and, like P-7,
by *recovering* a hypothesis rather than adding machinery.

**P-8 (all finite n).** Under (U) — every equilibrium hyperbolic and unstable
(d_s < n) — the union of stable manifolds ⋃_p W^s(p) is Lebesgue-null (each
relevant slice is covered by countably many local-flow preimages of an embedded
< n-disk), so a full-measure set of initial conditions avoids the equilibria
and, by the P-7 connectedness argument, has ω(x) ⊄ E. Gate open for a.e. x,
every dimension.

**Why this is the answer to (i).** The residue (i) I flagged 08-01 (source vs.
unstable) dissolves: a saddle's stable manifold, being a proper submanifold, is
measure-zero and cannot trap a positive-measure set. So OP-14's *original*
condition — "every equilibrium unstable" — already opens the gate (a.e.), with
hyperbolicity the only added regularity. The source hypothesis (R) of P-6/P-7
was strictly stronger than needed; P-7 is now the d_s ≡ 0 (everywhere-open)
corner of P-8. Mechanism = the continuous-time absorbing-region form of
"gradient descent avoids saddles almost surely" (Lee–Simchowitz–Jordan–Recht
2016 for the map; classical Kupka–Smale lineage). OP-16: no novelty.

**OP-14 net status.** P-5 (necessary: non-gradient) and P-8 (sufficient:
all-unstable-hyperbolic, a.e.) now bracket the gate tightly: in the hyperbolic
regime, **gate open a.e. ⟺ no sink ⟺ every equilibrium unstable**. The two-day
arc P-5→P-6→P-7→P-8 has walked OP-14 from "boxed open problem" to "settled gate
+ two named residues." Residue is now (a) non-hyperbolic equilibria (centre
manifolds — the stable *set* can be positive-dimensional-in-a-bad-way; needs a
centre-manifold or genericity hypothesis) and (b) classification of the
attracting set (the real n ≥ 3 difficulty, arguably unbounded).

**Method note (continued).** Second consecutive result that *removes* a
hypothesis (P-7 removed Poincaré–Bendixson; P-8 removed the source assumption)
rather than adding structure — the repo's prime directive ("delete assumptions
before adding concepts") is doing real work, not just governing prose: the
sharper theorem is the one that assumes less.

**Status.** P-8 written by the Writer, complete proof, self-audited. Formalizer
correction, same day: the proof should not assume global backward completeness
of Φ on ℝⁿ; nullity is obtained from local time-m flow preimages of
W^s_loc(p), not from global Φ_{−m} diffeomorphisms. Hyperbolic unstable ⟺
d_s ≤ n−1. Pending Formalizer (Codex) verification and maintainer promotion of
P-5..P-8. Next: residue (a) — a centre-manifold or transversality condition
for the non-hyperbolic case — is the last piece of the gate itself; (b)
classification is a different, harder programme.

## OP-14: P-9 — drop hyperbolicity to a linear escape direction (Writer)

**P-9 (all finite n).** Under (U′) — E finite, every p ∈ E has ≥ 1 eigenvalue
with Re > 0 (a linear escape direction; centre directions Re = 0 allowed,
hyperbolicity dropped) — the centre-stable manifold W^{cs}_loc(p) has dimension
n − d_u(p) ≤ n − 1, so by the forward-map argument W^s(p) ∩ C is null; finite
union null; gate open a.e., every dimension. Subsumes P-8 (no centre directions
= hyperbolic).

**What P-9 settles.** The measure-zero engine needs only d_u ≥ 1, not full
hyperbolicity. So OP-14's residue (a) sharpens to two thin cases where the
engine genuinely fails: **(a1)** d_u = 0 equilibria — unstable purely through
nonlinear centre dynamics (ẋ = x²; stable set {x ≤ 0} has positive measure),
non-generic by Kupka–Smale; **(a2)** non-isolated equilibrium continua (an
uncountable union of null centre-stable manifolds need not be null; wants a
normally-hyperbolic-repelling hypothesis). Neither is dimension-hard; both are
degeneracy questions.
