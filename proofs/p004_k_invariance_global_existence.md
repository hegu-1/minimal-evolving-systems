# P-4 · K-invariance and global existence for the coupled layers

STATUS: PROPOSITION — complete proof below. Codex/Formalizer, 2026-07-27.
Settles the remaining formal half of OP-18, conditional on the stated
Nagumo and balance hypotheses.

## Setting

Use the setting of P-2. Thus X and 𝓖 are Banach spaces, evaluation satisfies
(E1)–(E2), U : 𝓖 × X → 𝓖 is locally Lipschitz, and the coupled system is

  dδ/dt = F(δ),  dF/dt = U(F, δ).

Let K ⊂ 𝓖 be nonempty, closed, and convex. The admissible coupled state space
is X × K.

For F ∈ K, write T_K(F) for the contingent cone of K at F:

  T_K(F) = { V ∈ 𝓖 : liminf_{h↓0} dist(F + hV, K) / h = 0 }.

## Statement

**(a) K-invariance.** Assume the Nagumo tangency condition

  U(F, δ) ∈ T_K(F)        for every F ∈ K and δ ∈ X.        (N)

Then every local solution of P-2 with F₀ ∈ K satisfies F_t ∈ K throughout its
existence interval. Hence P-2 is a local well-posedness result on X × K, not
only on X × 𝓖.

**(b) Continuation criterion.** Let (δ, F) be the unique maximal solution on
[0, T_max), with initial data in X × K. If T_max < ∞, then

  limsup_{t↑T_max} (‖δ(t)‖_X + ‖F(t)‖_𝓖) = ∞.

Equivalently, any a priori bound on both layers over finite time intervals
extends the solution globally.

**(c) Two-layer balance sufficient condition.** Suppose there exist
nonnegative C¹ functionals B_X : X → [0, ∞), B_𝓖 : 𝓖 → [0, ∞) and
nondecreasing functions ρ_X, ρ_𝓖 : [0, ∞) → [0, ∞) such that

  ‖δ‖_X ≤ ρ_X(B_X(δ)),      ‖F‖_𝓖 ≤ ρ_𝓖(B_𝓖(F)).             (C)

Assume that on every finite time interval [0, T] there are nonnegative
integrable functions a_X, a_𝓖, b_X, b_𝓖, c_X, c_𝓖 ∈ L¹(0, T) such that along
every local solution with F_t ∈ K,

  d/dt B_X(δ_t) ≤ a_X(t) B_X(δ_t) + b_X(t) B_𝓖(F_t) + c_X(t),      (BX)
  d/dt B_𝓖(F_t) ≤ a_𝓖(t) B_𝓖(F_t) + b_𝓖(t) B_X(δ_t) + c_𝓖(t).    (BG)

Then every solution with F₀ ∈ K exists for all t ≥ 0 and remains in X × K.

## Proof

**(a)** The vector field on X × 𝓖 is

  G(δ, F) = (F(δ), U(F, δ)).

For the closed convex set X × K, the contingent cone is

  T_{X × K}(δ, F) = X × T_K(F),

because X has no boundary constraint and K is the only restricted factor.
Condition (N) is therefore exactly

  G(δ, F) ∈ T_{X × K}(δ, F)      for every (δ, F) ∈ X × K.

By the Nagumo invariance theorem for locally Lipschitz vector fields on Banach
spaces and closed convex constraint sets, X × K is positively invariant for
the local semiflow generated by G. P-2 gives existence and uniqueness in the
ambient space X × 𝓖; invariance says the same solution never leaves X × K
when F₀ ∈ K. ∎(a)

**(b)** Suppose T_max < ∞ and the trajectory is bounded:

  sup_{0≤t<T_max} ‖(δ(t), F(t))‖_{X×𝓖} < R.

The hypotheses bound G on the norm ball of radius R + 1. Indeed, (E2) gives
‖F(δ)‖_X ≤ C(R + 1)(1 + R + 1) there, and local Lipschitzness of U gives
‖U(F, δ)‖_𝓖 ≤ ‖U(0, 0)‖_𝓖 + L_{R+1}(‖F‖_𝓖 + ‖δ‖_X). Write the resulting
bound for ‖G‖ as M. For s < t < T_max,

  ‖(δ(t), F(t)) − (δ(s), F(s))‖
    ≤ ∫_s^t ‖G(δ(r), F(r))‖ dr
    ≤ M |t − s|.

Hence (δ(t), F(t)) is Cauchy as t ↑ T_max and converges to some
z_* = (δ_*, F_*) ∈ X × 𝓖. Part (a) gives F_t ∈ K for all t < T_max; since K
is closed, F_* ∈ K.

Apply P-2 with initial data z_* at time T_max. It gives a solution on
[T_max, T_max + ε] for some ε > 0. Concatenating the old solution with this
new one extends the maximal solution beyond T_max. Uniqueness from P-2 makes
the concatenation a single solution, contradicting maximality. Therefore a
finite maximal time forces blow-up in the product norm. ∎(b)

**(c)** Set

  V(t) = B_X(δ_t) + B_𝓖(F_t).

Adding (BX) and (BG) gives, for a.e. t ∈ [0, T],

  dV/dt ≤ A(t) V(t) + C(t),

where

  A(t) = a_X(t) + a_𝓖(t) + b_X(t) + b_𝓖(t),
  C(t) = c_X(t) + c_𝓖(t).

The functions A and C are integrable on [0, T]. Grönwall's inequality yields

  V(t) ≤ exp(∫₀ᵗ A)
         ( V(0) + ∫₀ᵗ C(s) exp(−∫₀ˢ A) ds )

for every t for which the solution exists in [0, T]. Thus V is bounded on
every finite interval. Coercivity (C) gives bounds on ‖δ_t‖_X and ‖F_t‖_𝓖 on
the same interval. The continuation criterion in (b) rules out finite-time
breakdown. Part (a) keeps F_t in K. Therefore the solution exists globally in
X × K. ∎(c)

## Remarks

- **R1 (what OP-18 now requires).** Local well-posedness is not enough for
  the admissible theory: one must also specify a K for which the update layer
  is tangent in the Nagumo sense, and balance estimates that control both the
  state layer and the law layer.
- **R2 (why convex K is assumed).** The closed-convex hypothesis is the
  standard setting where the tangent-cone condition is a clean invariance
  criterion. Nonconvex admissibility sets require a sharper viability theorem
  or additional regularity of the boundary; this proof does not claim that
  generality.
- **R3 (two-layer balance is the evolving analogue of P-1).** P-1 controls a
  fixed-law state layer. Here the same role is played by V = B_X + B_𝓖:
  state growth may be fed by law growth and law growth may be fed by state
  growth, but the sum still closes if the cross-terms are integrable-linear.
- **R4 (attribution).** The ingredients are classical: Nagumo invariance,
  ODE continuation in Banach spaces, and Grönwall comparison. The result is
  recorded to make OP-18 precise for 𝓜; no novelty is claimed (OP-16).
